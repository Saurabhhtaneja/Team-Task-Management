# 🚀 Team Task Manager (Full-Stack Project)

A full-stack web application that allows teams to manage projects, assign tasks, and track progress with role-based access control.

This project demonstrates backend architecture, authentication, and API integration using a lightweight frontend.

---

## 🧠 Features

### 🔐 Authentication
- User Signup & Login
- JWT-based authentication
- Secure API access

### 👥 Role-Based Access
- ADMIN: Manage projects and users
- MEMBER: View and work on assigned tasks

### 📁 Project Management
- Create and manage projects
- Assign members
- Track project details

### ✅ Task Management
- Create tasks
- Assign tasks to users
- Track status (TODO, IN_PROGRESS, DONE)
- Deadline tracking

### 📊 Dashboard
- Total tasks
- Completed tasks
- Pending tasks
- Overdue tasks

---

## 🏗️ Tech Stack

### Backend
- Java 17
- Spring Boot
- Spring Security (JWT)
- Spring Data JPA (Hibernate)
- H2 Database

### Frontend
- HTML
- CSS
- JavaScript (Fetch API)
